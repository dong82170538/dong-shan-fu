# 自有核心与数据合同

网页/CLI通过Store事务与Engine队列操作SQLite；FixtureAdapter是唯一启用适配器，合法平台适配器预留独立边界。桌面使用同一自有回环服务，预加载桥提供固定任务操作。MV3源码只连接回环fixture预览，没有商家内容脚本或真实发布。

商品、SKU、任务、事件、结果与计数持久化。商品保存和成功统计同一事务确认；异常保存不虚增成功。取消/暂停增加代际，迟到回调不可写成功；崩溃保留已提交结果，运行任务转interrupted并需显式resume。重复键相同参数返回原任务，不同参数冲突。线程物理并发有上限，超时的旧计算返回前继续占槽，避免逻辑超时导致并发超限。

金额为十进制字符串与明确币种，未知币种/未标记金额拒绝。mock_fee桌面/扩展profile分别以换汇费用/计算售价作为划线价基数；cost_plus为独立设计的另一个profile。不同业务resMoney保留context和currency，不混合汇总。费用和汇率是fixture输入，不是原后端模型或真实报价建议。

fixture必须source=test_fixture；账号限fixture命名空间；fake-login不能当作真实授权。真实连接/发布能力拒绝。JSON输入字段允许清单、HTTP读取期限/并发上限、固定日志错误码及CSV防公式注入适用于本地入口。

每日调度持久化IANA时区与UTC occurrence，错过默认记录后跳过，不静默补跑；重启不重复记录。上下文/会话代际使旧响应不能恢复失效会话。

能力清单区分自有实现、不可用商家能力与静态参考库存。68条路由参考仅是惰性自写JSON分析事实；保留引用位置便于核对，不是取得或执行了模块。CreateGoods等缺失能力保持NOT_IMPLEMENTED。隔离历史算术/状态特征只在tests/observed_legacy.py，不进入生产导入链。

这是单机回环工作台，不是完成多人鉴权的在线ERP。原生Electron/Windows/MV3宿主与商家集成均需单独实测；独立后台可在后续替换本地传输层，不把任务受理当作业务或发布完成。
